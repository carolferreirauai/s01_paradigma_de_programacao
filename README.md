## 💻 Paradigmas da Programação (S01) - Inatel

### 📌 Sobre o Repositório

Este repositório contém todos os códigos, listas de exercícios e trabalhos práticos desenvolvidos durante a disciplina **S01 - Paradigmas da Programação**, cursada no **Instituto Nacional de Telecomunicações (Inatel)**.

O objetivo da disciplina é compreender a evolução histórica das linguagens de programação, descrever sintaxe e semântica, e desenvolver aplicações práticas utilizando os paradigmas de programação imperativo, orientado a objetos, funcional e lógico.

### 🚀 Tecnologias Utilizadas

A disciplina explora diversas linguagens divididas em seus respectivos paradigmas:
* **Paradigma Imperativo:** Basic, LUA, Rust, Go
* **Paradigma Orientado a Objetos:** C++, C#, Ruby, Javascript
* **Paradigma Funcional:** LISP, Elixir, Haskell
* **Paradigma Lógico:** Prolog, Logtalk
* **Ambiente de Desenvolvimento:** VS Code

### 💡 Como Executar

Como o repositório abrange múltiplos paradigmas e linguagens, o processo de compilação e execução varia de acordo com a tecnologia de cada semana. 

1. Clone o repositório:
   `git clone https://github.com/carolferreirauai/s01_paradigmas_da_programacao.git`

2. Navegue até a pasta correspondente à linguagem desejada via terminal.

3. Para linguagens compiladas como C++ (exemplo):
   `g++ nome-do-arquivo.cpp -o executavel`
   `./executavel` (Linux/Mac) ou `executavel.exe` (Windows).

4. Para linguagens interpretadas, como Python ou Ruby:
   `ruby nome-do-arquivo.rb`
   
*(Consulte instruções específicas de compilação/execução dentro das pastas de linguagens como Haskell, Prolog ou Rust).*
